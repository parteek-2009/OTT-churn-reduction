# Governance and Legal Notes (US, v1)

Rules and limits that affect what data the project can use. Jetflix is fictional, so
these notes describe how a real US platform would handle it.

## Consent
- Consent means a user has given permission for a specific purpose.
- It is stored per user as simple yes/no flags, for example email opt-in and WhatsApp opt-in.
- **Data consent:** users agree to their data being used for purposes like personalization.
- **Contact consent:** users agree to receive marketing messages on a given channel.
- Users can withdraw consent at any time, and that must be respected.
- Principle: use data only for what users agreed to.

## US rules to keep in mind
Starting point only. Verify with compliance.
- **CAN-SPAM:** marketing email must include an unsubscribe option.
- **TCPA:** marketing texts need prior consent.
- **State privacy laws** (for example California's CCPA/CPRA): users can ask what data is held and ask for it to be deleted.
- **WhatsApp:** business messaging requires user opt-in under WhatsApp's own policy.
